Homework assignment for AI Engineer | nexos.ai

Background
You are an AI engineer at nexos.ai. The company's LLM Gateway lacks a "smart routing" feature that competitors have. Competitors' routers make decisions based on different prompt properties and pre-defined LLM attributes (e.g., cost, speed, LLM feature set). You need to conduct research and build proofs of concept on how such a smart routing feature might be implemented.

Assignment
You need to test out a few possible solutions:

1. Prompt Property Evaluation
Evaluate different prompt properties that could be used to make routing decisions to different LLMs.

x. Fine-tuning Approach
Create a small dataset and evaluate a fine-tuning approach using a method of choice. Note: Optimization for routing to all possible LLMs is not required; focusing on a couple of selected LLMs is sufficient for this assignment.

After the experiments, you decided to:

1. API Development
Write an API for the LLM Gateway team to test one of the experiments (either prompt engineering or fine-tuning).

2. Documentation
Prepare a document detailing findings and experiment results.

3. Suggestions
Provide suggestions to the LLM Gateway team on how to proceed with feature implementation.

Constraints of a task:

1. Language: All code must be written in Python.
2. Documentation Format: All experiments must be documented in a Notebook.
3. Reproducibility: Experiments should be reproducible, and fine-tuned models should be available for download.
4. Bonus: Deploying the fine-tuned model is a bonus task.
